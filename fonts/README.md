# The headline font

`thumbfree-serif.woff2` is a subset of Source Serif 4 Display Regular 4.005 by Adobe, under the SIL Open Font License 1.1 (`OFL.txt`). The licence reserves the name "Source", so this modified copy is named "ThumbFree Serif".

It keeps Basic Latin, Latin-1 and the curly quotes, dashes, bullet and ellipsis, with kerning and ligatures and without hinting. It was made with fontTools (`subset.Subsetter`, the names changed in the `name` table) and compressed to WOFF2.
