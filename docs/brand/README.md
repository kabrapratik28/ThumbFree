# ThumbFree brand kit

| Folder | What is there |
|---|---|
| `common/` | Shared by both apps: the logo and bubble art, the colours, the fonts, the illustration style, and the repository README's screenshots and buttons (`common/README.md`) |
| `android/` | Google Play: the store screenshots, the feature graphic, the 512 x 512 icon, the listing text, the illustrations and prompts, and the scripts that build and check them (`android/README.md`). `android/app-screenshots/` holds captures of the app's own screens, light and dark. |
| `ios/` | App Store: the store screenshots and their raw captures, the 1024 x 1024 icon, the listing text, the illustrations and their prompts, and a README on rebuilding them (`ios/README.md`). `languages.png` and `names.png` are the same files as Android's `android-7.png` and `android-5.png`. |

The iPhone and Android illustrations show the same scenes but were generated separately, so each platform keeps its own set in its `art/` folder until one shared set is chosen.

Screenshots and store images show made-up content only.
